# react-ui-dev (Vite + React)

Minimal Vite + React starter with a base Hello World component.


Setup and run:

```bash
cd react-ui-dev
npm install
npm run dev
```

The dev server uses Vite's default port (5173).

Tailwind:

Tailwind is included. `src/index.css` contains the Tailwind directives. After `npm install` the dev server will process Tailwind utilities.
